# Schémas de la section sécurité du JWT (TD4)

Les fichiers `.mmd` sont les sources [Mermaid](https://mermaid.js.org/) des images `.svg` affichées dans `tutorials/tutorial4.md`.
Après avoir modifié une source, régénérez l'image correspondante avec [mermaid-cli](https://github.com/mermaid-js/mermaid-cli) :

```
mmdc -i csrf.mmd -o csrf.svg -b white
```

Les sources peuvent aussi être éditées et prévisualisées sur <https://mermaid.live>.
